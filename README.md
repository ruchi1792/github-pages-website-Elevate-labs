
# 🚀 Static Website Deployment Using GitHub Pages

🌐 **Live Website:** https://ruchi1792.github.io/github-pages-website-Elevate-labs/

📂 **GitHub Repository:** https://github.com/ruchi1792/github-pages-website-Elevate-labs

## 📌 Project Overview

This project demonstrates how to create, customize, and deploy a static website using **HTML, CSS, Git, GitHub, and GitHub Pages**.

The website was upgraded into a professional Cloud & DevOps portfolio showcasing technical skills, projects, and certifications.

## 🎯 Objectives

- 🖥️ Create a static website using HTML and CSS.
- 🎨 Customize the website with professional styling.
- 🔧 Track source code changes using Git.
- 📦 Store and manage code using GitHub.
- 🌍 Publish the website using GitHub Pages.
- 📱 Use responsive CSS for different screen sizes.
- 📸 Document the implementation with screenshots.

## ⚙️ Deployment Steps

1. 📝 Created the `index.html` file.
2. 🎨 Added CSS to customize the website.
3. 🔧 Initialized and managed the project using Git.
4. 📦 Pushed the source code to GitHub.
5. ⚙️ Opened **Settings → Pages** in the repository.
6. 🌿 Selected the `main` branch and `/ (root)` folder.
7. 🚀 Enabled GitHub Pages deployment.
8. 🌍 Opened and verified the live website.
9. 📸 Captured screenshots as project evidence.


# Static Website Deployment Using GitHub Pages

## Project Overview

This project demonstrates how to create and deploy a static website using HTML, CSS, Git, GitHub, and GitHub Pages.

The website was customized into a Cloud and DevOps portfolio showcasing technical skills, projects, and certifications.

## Objectives

- Create a static website using HTML and CSS.
- Track changes using Git.
- Host source code in a GitHub repository.
- Deploy the website using GitHub Pages.
- Customize the website with responsive CSS styling.

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages
- WSL Ubuntu

## Architecture

1. Create the website using HTML and CSS.
2. Initialize a Git repository locally.
3. Commit and push the code to GitHub.
4. Configure GitHub Pages to publish from the main branch and root folder.
5. Access the deployed website through its public URL.

## Deployment Steps

1. Create `index.html`.
2. Initialize Git and commit the source code.
3. Push the code to the GitHub repository.
4. Open Settings → Pages.
5. Select Deploy from a branch.
6. Select `main` and `/ (root)`.
7. Save and verify the published website.

## Outcome

Successfully deployed a static website using GitHub Pages and customized its appearance with CSS.
